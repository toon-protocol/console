# Spec wire fixtures, copied

These five files are copied **verbatim** from TOON_Network's
`docs/spec/fixtures/wire/`, where they are generated by the provider's own wire
tests (`toon-provider`, `tests/wire_fixtures.rs`) and checked byte for byte by
its CI. They are not written here and are not edited here: to refresh one, copy
it again.

They are real signed events, signed by the spec's publisher test key, so the
console's own reader (`nostr.ts`, TOON_Network#91) verifies them exactly as it
verifies a stranger's event off a relay — id re-derived, signature checked.
That is what makes them worth having: a fixture the console signed for itself
would prove that the console agrees with the console.

| File | What it is |
|---|---|
| `registry.template.json` | A Template, kind 30436 (spec §8.3) — `static-site`, naming its image by content address and an Image Registry entry |
| `registry.image_entry.json` | The Image Registry entry that Template names, kind 30434 (§8.1), with both source types |
| `registry.blob_record.json` | A Blob Record, kind 30435, inline `parts` (§8.2) |
| `registry.blob_record.paged.json` | The same blob as a **paged** record (§8.2, §11 item 2) |
| `spawn_image.registry_entry.json` | A spawn whose `image` is the registry-entry form (§6.2) — the shape an expansion has to produce |

`templates.test.ts` and `template-spawn.test.ts` read them from here.
